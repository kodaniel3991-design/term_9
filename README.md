## 실행 순서

### 1. 새 디자인 파일 만들기

Figma 데스크톱 앱을 열고 새 **Design file**을 생성합니다.

### 2. 플러그인 불러오기

상단 메뉴에서:

```
Plugins → Development → Import plugin from manifest...
```

파일 선택 창이 뜨면 이 폴더의 **`manifest.json`** 을 고릅니다.

> `code.js` 가 아니라 `manifest.json` 입니다. 두 파일은 같은 폴더에 있어야 합니다.

### 3. 실행

```
Plugins → Development → 반려동물 건강기록 프로토타입 빌더
```

몇 초 뒤 캔버스에 프레임 4개가 나란히 생성되고 `완료 — 프레임 4개, Hotspot 9개 생성` 메시지가 뜹니다.

### 4. 확인

우측 상단 **Prototype** 탭을 누르면 프레임 사이에 연결선이 보입니다.
▶ (Present) 버튼으로 실제 클릭 동작을 확인할 수 있습니다.

### 5. 공유 링크 만들기

우측 상단 **Share** → `Anyone with the link` → **can view** → **Copy link**

이 링크가 과제 제출용 산출물 ③ 입니다.

## 만들어지는 화면 흐름

```
        ┌──[전체 보기]──▶ 목록 ──[03.28 행]──▶ 상세
        │                  │                    │
  홈 ───┤                  │                    │
        │   ◀──[뒤로]──────┘   ◀────[뒤로]──────┘
        │
        └──[등록 FAB]──▶ 입력 폼 ──[저장하기]──▶ 홈
                            │
                            └──[닫기]──▶ 목록
```

| # | 출발 | 트리거 영역 | 도착 |
|---|---|---|---|
| 1 | 홈 | 전체 보기 | 목록 |
| 2 | 홈 | 03.28 기록 행 | 상세 |
| 3 | 홈 | 등록 FAB (+) | 입력 폼 |
| 4 | 목록 | 뒤로 (←) | 홈 |
| 5 | 목록 | 03.28 기록 행 | 상세 |
| 6 | 목록 | 등록 FAB (+) | 입력 폼 |
| 7 | 상세 | 뒤로 (←) | 목록 |
| 8 | 입력 폼 | 닫기 (×) | 목록 |
| 9 | 입력 폼 | 저장하기 | 홈 |

순환 구조라 어느 화면에서 시작해도 막다른 경로가 생기지 않습니다.

## Hotspot 위치가 어긋날 때

클릭 영역은 이미지 비율 기준으로 계산되어 있어 대부분 맞지만, 미세하게 어긋나면 직접 조정할 수 있습니다.

**위치를 눈으로 보려면** `code.js` 첫 부분의

```js
var SHOW_HOTSPOTS = false;
```

를 `true` 로 바꾸고 다시 실행하세요. 주황색 반투명 사각형으로 표시됩니다. 위치를 확인한 뒤 `false` 로 되돌려 다시 실행하거나, 캔버스에서 사각형을 직접 드래그해 맞추면 됩니다.

레이어 이름이 `hotspot — 전체 보기 → 목록` 형식이라 레이어 패널에서 바로 찾을 수 있습니다.

## 이어서 할 후가공

플러그인은 배치와 연결까지만 처리합니다. 아래는 Figma에서 직접 얹는 작업입니다.

| # | 화면 | 처리 |
|---|---|---|
| 1 | 목록 | 비활성 홈 탭이 네이비 실선 → 회색 `#737B87` 로 덮기 |
| 2 | 입력 폼 | 상단 상태바 여백 추가 (다른 화면과 시작점 정렬) |
| 3 | 입력 폼 | 저장하기 버튼 하단 여백 확보 |
| 4 | 입력 폼 | 우상단 `저장` 중복 버튼 제거 |
| 5 | 상세 | 삭제 버튼 경고색 처리 |
| 6 | 홈 | "4주 전" 숫자·단위 서체 규칙 통일 |

사각형이나 텍스트 레이어를 위에 얹는 작업이라 Figma 기본 기능으로 처리됩니다.

## 기술 메모 (작업 로그용)

- 이미지는 810 × 1440 JPEG로 리샘플링해 base64로 `code.js` 에 내장했습니다. 별도 에셋 업로드 없이 플러그인 하나로 완결되며, 파일 크기는 약 0.49 MB입니다.
- Figma 플러그인 샌드박스에는 `atob` 이 없어 base64 디코더를 직접 구현했습니다.
- 프로토타입 연결은 API 버전에 따라 `setReactionsAsync` 와 `reactions` 프로퍼티 중 사용 가능한 쪽으로 분기합니다.
- 프레임 크기 405 × 720은 정확히 9:16입니다. `iPhone 15 Pro` 프리셋(393 × 852, 비율 0.461)을 쓰면 시안 위아래가 잘리므로 커스텀 크기를 사용했습니다.
